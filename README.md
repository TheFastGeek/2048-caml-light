# 2048 in Caml Light

## Overview
Just the 2048 made with Caml Light, a programming language that is obsolete since 2002.

## How to play
Use the WASD keys or the numpad arrows to move the cells across the board. Add up equal numbers to get bigger ones. Each addition increases your score. Your goal is to reach the highest score possible !

## Setup
I couldn't convert the game file into an executable. So you have to install a Caml Light editor in order to play it.\
Check out [this page](https://caml.inria.fr/download.en.html) for the one I used.
